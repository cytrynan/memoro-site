memoro プライバシーポリシー

最終更新日: 2026-10-20

概要

memoro（以下「本拡張機能」）は、ユーザーのプライバシーを最優先に設計された Chrome 拡張機能です。あなたが作成した暗記カードや学習データは、一切収集・送信しません。購入手続き・購入の復元を行う場合にのみ、決済のため ExtensionPay / Stripe と通信します。

購入機能（地域別価格を含む）・復習タイマー・ご意見フォームへのリンクは、バージョン 0.3.0 以降の機能です。

収集する情報

学習データは収集しません。 本拡張機能は、あなたが作成した暗記カード・復習の進捗・閲覧履歴・利用状況（アナリティクス）を一切収集しません。Cookie やトラッキング技術も使用しません。

  • 氏名・メールアドレス等の個人情報を学習機能のために取得することはありません
  • 閲覧履歴・アクセス履歴を取得・記録しません
  • 利用状況・分析（アナリティクス）データを取得しません

例外（購入した場合のみ）: 有料版（買い切り。日本では600円、その他の地域は地域の通貨で表示）を購入した場合に限り、購入状態の確認・別端末での購入の復元のために、決済サービス ExtensionPay（Stripeを利用）と通信します。この際、購入時に入力したメールアドレスを含む購入状態の情報が、ExtensionPayライブラリによってchrome.storage.sync（利用できない場合はchrome.storage.local）に保存されます。Chromeの同期機能が有効な場合、この情報はお使いのGoogleアカウントを通じてあなたの他の端末にも同期されます（学習データ本体である暗記カードは引き続きchrome.storage.localのみに保存され、同期されません）。この情報は本拡張機能の画面（カード管理・エクスポートファイルなど）には一切表示・出力されません。詳細は下記「通信が発生する操作」をご覧ください。

価格の地域判定について: 購入ボタンに表示する価格は、お使いの端末のタイムゾーンと言語設定から、端末内でお住まいの地域を判定して決めます。タイムゾーンや言語設定そのものは外部に送信しません。購入ボタンを押したときに限り、判定した地域の価格プランの名前（例：米ドルの価格プラン）が決済ページの表示のために ExtensionPay に伝わります。

データの保存

ユーザーが作成した暗記カード（表面・裏面のテキスト、タグ、出典ページのURLとタイトル、復習の進捗）および設定は、お使いのブラウザ内のローカルストレージ（chrome.storage.local）にのみ保存されます。

  • カードと学習データが本拡張機能によって外部に送信されることは一切ありません
  • 開発者を含む第三者が、これらのデータにアクセスすることはできません
  • 出典URLは http / https のみを保存し、それ以外の形式は保存時に破棄されます
  • 復習タイマーの設定（通知のオン/オフ・通知する時刻・その日に通知の判定をしたかどうか）も、同じくブラウザ内にのみ保存されます

通信が発生する操作（購入機能について）

本拡張機能は、決済のために ExtensionPay（決済処理は Stripe が担当）と通信する機能を持ちます。通信が発生するのは次の操作を行ったときに限られ、それ以外の通常利用（インストール・カード作成・復習・カード管理・エクスポート/インポート（JSON・CSV）を含む）では一切通信しません。

操作 通信
拡張のインストール・カード作成・復習・編集・削除・エクスポート/インポート（JSON・CSV） なし
オプション画面で購入ボタン（日本では「600円で無制限にする（買い切り）」）を押す あり（プラン情報の取得・決済ページの表示・購入状態の確認）
オプション画面で「購入済みの方はこちら」を押す（別端末で購入した場合の復元） あり
オプション画面で「購入状態を再確認」を押す あり
上記以外（購入完了後の通常利用を含む） なし

本拡張機能はバックグラウンドでの定期的なライセンス確認を行いません（上記操作を行わない限り、ExtensionPay への通信は発生しません）。

外部ページへのリンク（ご意見フォーム・ストアのレビュー）

オプション画面やポップアップの「ご意見・ご要望を送る」「ご意見を送る」「ストアでレビューを書く」を押すと、ブラウザの新しいタブで Google フォーム、または Chrome ウェブストアのレビュー欄が開きます。本拡張機能自身は、これらのページへ何も送信しません。 ご意見フォームの URL には、回答の参考にするため本拡張機能のバージョン番号（例: 0.3.0）だけを付けます。カードの内容や個人情報は付けません。開いたページで入力・送信した内容は、各ページの運営者（Google）のプライバシーポリシーに従って扱われます。

第三者への提供

学習データ（カードの内容など）を第三者へ提供・販売することはありません。購入手続きに限り、決済処理のため以下の委託先と通信します。

委託先 用途 プライバシーポリシー
ExtensionPay LLC 拡張機能向け決済プラットフォームの提供 extensionpay.com/privacy.html
Stripe, Inc. クレジットカード決済処理（ExtensionPay経由） stripe.com/jp/privacy

権限の利用目的

権限 利用目的
storage 作成した暗記カードと設定（購入状態を含む）をブラウザ内に保存するため
contextMenus 右クリックメニュー「memoroにカードを追加」を表示するため
activeTab / scripting 右クリックメニュー・ショートカットキー・ポップアップのボタンを操作したときに、表示中のタブへ保存ダイアログを一時的に表示するため
alarms 「今日の復習」枚数の表示を定期的に（最大1時間ごと）更新し、復習タイマーの通知時刻を予約するため
notifications（任意） 復習タイマーの通知をオンにした場合だけ、設定した時刻（1日1回）に「今日の復習が◯枚あります」と表示するため。期日の来たカードが無い日は表示しません。通知にカードの内容（表面・裏面）は含めません

host_permissions は要求しません。購入機能のための決済サーバーへの通信も、追加の恒久的なサイトアクセス権限なしで行われます。いずれの権限も、学習データの外部送信には使用しません。

notifications は任意の権限です。インストール時には要求せず、利用者が復習タイマーの通知をオンにしたときにだけ Chrome が許可を確認します。通知は Chrome の機能でお使いの端末に表示されるもので、通知のために外部と通信することはありません。通知をオフにすれば以後は表示されません。

データの削除方法

  • 個別のカード: 拡張機能のオプションページ（カード管理）から削除できます
  • 購入状態の情報: Chrome から本拡張機能をアンインストールすると削除されます。ただしchrome.storage.syncに保存されている場合、Chromeの同期機能により他の同期済み端末にも複製されているため、完全に削除するには全端末でアンインストールするか、Chromeの同期設定から該当データを削除する必要があります
  • すべてのデータ: Chrome から本拡張機能をアンインストールすると、保存されたすべてのデータ（学習データ・購入状態）が削除されます

子どものプライバシー

本拡張機能は学習データを収集しないため、年齢を問わず安全にご利用いただけます。有料版の購入には保護者の同意のもとクレジットカード等の決済手段が必要です。
