加到 Chrome 了解使用方式

3 個步驟即可使用

選取。填寫。複習。

memoro 是一款 Chrome 擴充功能。選取網頁上想記住的文字，在右鍵選單中選擇「新增卡片至 memoro」，然後在對話方塊中儲存，即可建立單字卡（記憶卡片）。之後每天花幾分鐘，完成工具列圖示提示的「今日複習」即可。

  1. 1

    選取

    選取網頁上想記住的文字，按右鍵 →「新增卡片至 memoro」。

  2. 2

    填寫

    在出現的對話方塊中輸入一個簡短的問題，然後儲存（也可以留白，所選文字會直接成為正面內容）。

  3. 3

    複習

    點選工具列圖示上的「今日複習」徽章，再用「再來一次 / 良好 / 簡單」進行自我評估即可。

主要功能

只複習今天該複習的。

間隔重複（SM-2 演算法）只會挑選已到複習日期的卡片來複習。適合鞏固不想讀完就忘的知識，例如證照考試術語、英文單字，以及工作中用到的專業知識。

  • 右鍵選單建立從所選文字建立卡片（自動記錄來源網頁的 URL 和標題）。
  • 只安排今日複習透過 SM-2 間隔重複，自動安排今天需要複習的卡片。
  • 三種評估，調整下次複習依據三種自我評估選項（再來一次 / 良好 / 簡單），自動調整下次複習日期。
  • 卡片管理頁面清單、關鍵字搜尋、編輯、刪除。
  • JSON 匯出／匯入JSON 格式的匯出／匯入，用於備份或手動移轉到其他裝置。無論是否達到卡片數量上限，隨時可用。
  • 快速鍵也可使用快速鍵將選取的文字製成卡片（Windows：Alt+Shift+M；Mac：Control+Shift+M；ChromeOS：Alt+Shift+K。可在 chrome://extensions/shortcuts 變更）。
  • 用標籤整理使用標籤整理卡片，依標籤檢視或複習。
  • 適用於 Anki 的 CSV匯出適用於 Anki 的 CSV 檔案（以逗號或定位字元分隔）。
  • 用鍵盤複習也可以用鍵盤複習（按空白鍵「查看答案」，按 1/2/3 評分，按 H 鍵取得「提示」）。
  • 復原評分評分點錯時，可以用「復原」取消上一次評分。
  • 在答案畫面編輯可以在答案畫面直接編輯卡片。
  • 從檔案匯入卡片匯入 CSV／TSV（從 memoro 或 Anki 匯出的檔案。若已有正面和背面都相同的卡片，則不會重複新增；免費版最多 50 張卡片）。
  • 從彈出視窗建立也可以透過彈出視窗中的「將選取的文字做成卡片」建立卡片。在觸控裝置上，按鈕會放大，方便點按。

遺忘曲線與複習計時器

距離下次複習，
還有幾小時。

人學過的東西會隨著時間慢慢遺忘。心理學家艾賓豪斯在 1885 年以自己為對象測得這條「遺忘曲線」，2015 年的重現實驗也報告了與原始資料非常相似的結果。memoro 採用每複習一次就拉長間隔的間隔重複（SM-2 演算法）來決定下次複習日期，並透過複習計時器通知你複習時間。

  • 複習計時器

    在彈出視窗中顯示距離下次複習還有多久，以及日期和卡片數量。在卡片管理頁面中也可以查看每張卡片的下次複習時間。

  • 每天一次的通知（選用）

    在你設定的時間（預設 21:00），僅在有到期卡片的日子發送通知。通知只顯示卡片數量，不顯示卡片內容。

  • 記憶保持曲線

    依據你的卡片的平均值繪製的示意圖，呈現複習間隔如何逐漸拉長。它不是實測資料，只是說明間隔重複原理的參考。

複習結束後，查看今日成果

完成複習後，如果有已記起的卡片，完成畫面會顯示今天已記起的卡片數量。如果記起的卡片上次也記起了，還會顯示距上次複習平均過了多少天、距下次複習的天數增加了多少（例如：平均 4 → 11 天），並在同一張示意圖中以兩條遺忘曲線呈現今天複習與不複習兩種情況下的遺忘過程（曲線為示意圖，並非對記憶量的實測）。

幫助回想的功能

  • 提示

    想不起答案時，按下「提示」即可從開頭逐步顯示答案（日文每次顯示幾個字元，英文等語言每次顯示一個單字，不會顯示完整答案）。使用提示後，即使選擇「簡單」，也會以「良好」處理，避免複習間隔延長過多。

  • 「已鞏固」的計算方式

    在首次成功回想的那一天之後，連續三次於三個不同的日子成功回想的卡片會計為「已鞏固」，並顯示在完成畫面和卡片清單中（我們以記憶研究中使用的再學習流程作為參考）。

  • 睡前複習

    複習提醒的預設時間為 21:00。有研究指出，學習後幾小時內入睡可能有助於記憶鞏固，因此我們選擇了睡前時段（可在設定中變更時間）。

  • 資料來源：H. Ebbinghaus《Über das Gedächtnis》(1885)／英譯本 Memory, Chapter VII (Ruger & Bussenius, 1913)
  • J. M. J. Murre & J. Dros, “Replication and Analysis of Ebbinghaus’ Forgetting Curve”, PLOS ONE 10(7), 2015
  • P. A. Wozniak, Optimization of learning (1990) — Algorithm SM-2

隱私

卡片內容，
只留在你的裝置中。

  • 卡片內容不會傳送到外部

    建立的卡片和學習進度僅儲存在你的瀏覽器中（chrome.storage.local），不會傳送到外部伺服器。

  • 僅在購買流程中通訊

    只有在購買或還原買斷解鎖（包括重新確認購買狀態）時，才會為處理付款而與 ExtensionPay / Stripe 通訊。其他操作（包括建立卡片、複習、卡片管理、匯入和匯出）皆不進行通訊。

  • 無需帳號

    無需註冊或登入（僅在購買時需要提供付款資訊）。

  • 無廣告、無追蹤。

權限說明（僅限必要權限） 以下是 memoro 要求的權限及其用途。不會取得瀏覽紀錄，也不會持續存取所有網站。

storage 將建立的卡片和設定（包括購買狀態）儲存在瀏覽器中。
contextMenus 在右鍵選單中顯示「新增卡片至 memoro」。
activeTab / scripting 僅在點選選單項目、按下快速鍵或點選彈出視窗中的「將選取的文字做成卡片」時，於目前分頁顯示儲存對話方塊（不會持續存取所有網站）。
alarms 定期（最多每小時一次）更新顯示「今日複習」數量的徽章，並預約複習計時器的提醒時間。
notifications（選用） 僅在你開啟複習計時器提醒時，於設定的時間顯示「今天有 N 張卡片需要複習」（開啟時 Chrome 會要求權限；通知不包含卡片內容）。

※ 請勿在卡片中儲存機密資訊或密碼等秘密資訊。資料未經加密，儲存在本機。
